# Public web application

The Weather Node server uses React Router 8.5.0 SSR and an explicit Express entrypoint. Every public
page is readable without JavaScript; enhanced navigation, current-condition polling, chart interaction
and quality selection use the locally bundled client code. There is no PWA, external asset fetch or
persistent browser cache for weather data.

The read-only server consumes only the fixed `API_ORIGIN=http://api` Service on port 80. It forwards no
cookies or authorization headers, follows no redirects, allows only the listed public API paths, and
bounds each request to 6 seconds and 4 MiB. At most twelve upstream requests run at once: three per
document, because Today reads current conditions, the metric registry and recent events concurrently. API-backed
document/data responses have four slots and a 15-second absolute deadline, matching the initial
512 MiB web memory limit. Static files, process health, the loader-less About and Search pages and the
lazy route manifest (`/__manifest`) do not consume those slots. Overload is reported as "Weather is
busy" with `503` and `Retry-After: 5`, never as "API unavailable": a document request gets that text, and
a hydrated client navigation's `.data` request gets the body `busy`, which the root error boundary
renders as the same busy state. Failures render
sanitized unavailable states. The process has no database, camera, object-store or model credential.

HTTP is on `PORT` (3000); metrics use a separate `METRICS_PORT` (9000). `/healthz` and `/readyz` identify
process health. All routed document responses are no-store, deny framing (except `/embed/weather/`,
which only `https://vallery.net` may frame; see [embed](embed.md)), and use a fresh script nonce
with no unsafe-inline/eval. The nonce is generated by Express and overwrites the incoming internal
nonce header before React Router sees it. Root hydration keeps the original document nonce through
client navigation. One trusted ingress proxy hop is configured, and forwarded authority is normalized
to the allowlisted public host. Logs contain only fixed route templates, status and latency.

Current data is seeded by the loader into a request-local QueryClient. Polls use one shared identity,
15-second spacing, a 120-second backoff ceiling, no focus/reconnect retry, and cancel when hidden.
The API-unavailable label retains old observation times and continues aging values. A successful
response containing unavailable/null measurements instead invalidates the earlier cached numbers;
it does not claim a transport failure. An API `cached` state describes API fallback, without guessing
whether the physical station feed failed. The shared `useCurrent(initial, apiUnavailable, options)`
hook additionally supports `refreshOnResume: true` and `jitterFraction` (clamped to 0–0.2) for the
separate embed surface; Today keeps its existing next-tick resume and exact 15-second base interval.
Repeated visibility events do not create overlapping refreshes.

Display units are URL state; source values stay canonical. Registry discovery supplies required
rational affine conversion recipes and labels. If discovery is unavailable or mismatched, the UI
shows canonical source units with an explicit conversion-unavailable notice. It never substitutes
an independently guessed conversion. Missing is a reasoned null, never a fabricated zero. Windowed
rain is labelled derived and is excluded from the direct-observation selector.

History identifies raw `resolution_seconds: 0` as unbinned source observations, not a physical
sampling cadence of zero seconds. Positive-resolution aggregate payloads cannot enter that view.
Bounded API input errors retain only a whitelisted code and numeric resolution suggestion; messages
and request identifiers never enter hydration. A rejected raw query never silently selects an
aggregate or another statistic. History shows the source interval, reported gaps and support metadata. uPlot receives
nulls at missing intervals and has a complete SSR table alternative. Exports are bounded JSON pages;
following a cursor or choosing another interval exposes older retained data. The archive calendar
selects solar-cycle dates; its separate bounded catalog clearly labels its filter/pagination scope.
Day pages retain three cameras by two segments, with honest uncommissioned metadata states.

Published and partial-coverage video products receive a native player; a partial product shows a
visible coverage label. Unavailable/expired products retain text and coverage but expose no player
or poster. The player never autoplays; quality changes retain the
playhead and pause other players. Native downloads and the JSON sidecar stay on the same origin.

Fonts are the exact approved Fontsource 5.3.0 IBM Plex Sans Variable and Mono members. Their original
OFL notices are served at `/fonts/OFL-sans.txt` and `/fonts/OFL-mono.txt`.
`python scripts/check_web_assets.py` verifies all four hashes against `font-provenance.json`.
The fixture source contains synthetic timestamps/measurements only and is never imported by a live
route. Tests and fixture API code are excluded from the runtime image.

Lightweight verification: `pnpm --dir web typecheck`, `pnpm --dir web lint`, and `pnpm --dir web test`.
Builds, Playwright and synthetic media generation run only through approved
in-cluster fleet CI. The shared Weather CI tooling image bakes PostgreSQL, exact Playwright 1.64.1
browsers and system libraries, and qualified FFmpeg 9.0.2; `bootstrap-browser.sh` only verifies the
readable `/opt/ms-playwright` closure and generates synthetic fixtures as UID1001. It never runs apt
or installs system libraries at validation runtime. The browser check also scans every compiled client
asset, including lazy routes, for private endpoints/configuration, fixture identifiers and source maps
without printing asset contents. WX-20 is not complete until the three-engine responsive/axe/JS-off/chunk-reload checks
and live pinned web image have passed. Source tests alone do not establish those outcomes.

Metrics `weather_web_api_requests_total{route,result}`, `weather_web_api_inflight` and
`weather_web_ssr_inflight` distinguish API transport/shape/body-budget/admission failures from an HTTP
200 degraded page. `weather_web_ssr_failures_total{reason}` records overload, absolute deadline
termination and uncaught render failures, including connections closed before an HTTP finish event. Labels are fixed route templates and a bounded result vocabulary; no query,
station identity or upstream address is logged. `weather_web_request_duration_seconds` covers HTTP
status and asset 404s. Monitoring-stack owns scraping and alert/probe policy.

The web Dockerfile pins the commissioned predecessor and retains its hashed assets. A build emits
`.weather-assets.json` with only that build's own path, size and SHA-256 identities before copying
one predecessor. Subsequent builds read that inventory, verify every predecessor byte and reject
filename collisions with different content. The closure is limited to 512 files / 64 MiB total and
8 MiB per file; older ancestors do not accumulate. The original scaffold image has one explicit
legacy-inventory exception; remove that flag when repinning to the first inventoried web image.
A held tab that requests a chunk the new build no longer has reloads exactly once
(`app/lib/chunk-reload.ts`, guarded by a `sessionStorage` timestamp); a second failure within 60 seconds
surfaces instead of looping, and a tab still open at a later promotion gets one fresh recovery.
The e2e fixture ingress mirrors `deploy/k8s/ingress.yaml` routing: `/api/` to api, everything else to
web. `/media/` and `/downloads/` are added there only when #20 routes them in production.

`ci.sh browser` runs the single-worker fixture matrix in all three engines, then writes the existing
`/workspace/ci-test-report.json` output parameter. It requires every configured case to pass without
skips or retries and records checksums for 27 synthetic Today/history/About screenshots. ROOT collects
the listed files while the exact run Pod main container is Running and verifies their hashes for visual review. A terminated main container cannot reliably be read even during PodGC grace.
The report is capped at 60 KiB; original test output and traces remain in `artifacts/` for that run.

The runtime schemas remain independent of generated OpenAPI. The synthetic registry fixture is
serialized from the actual code-first discovery model, including all 16 canonical metric identities,
required conversion recipes and explicit null cadence. The source-hashed pure ASGI-to-Node receipt
in `evidence/public-web-alignment-20261024.json` proves current serialization defaults, cached source
times, raw history and discovery pass the actual web parser. It records no database, server socket,
browser, build or deployment qualification.

Reproduce that bounded optional receipt after API adoption with:

```sh
uv run --frozen python scripts/check_web_contract_alignment.py
```

For pre-merge source coordination, `--api-source <isolated-api-checkout>` binds that exact Git
revision and its model/router/service hashes. Node must be the pinned 24.22.1 from the CI bootstrap.
The receipt also binds the web parser, input fixtures and helper hashes; the independent web unit
checks remain runnable before the API modules exist and never consume generated OpenAPI.

For the standalone browser qualification only, set these environment variables on the fixed committed
command before `scripts/bootstrap-ci.sh`:

```sh
WEATHER_CI_IN_CLUSTER=1 WEATHER_BROWSER_CAPTURE_OPERATION=<stable-operation-id> \
WEATHER_BROWSER_CAPTURE_SOURCE=<exact-40-character-source-sha> \
WEATHER_BROWSER_CAPTURE_SECONDS=180 \
bash scripts/bootstrap-ci.sh bash scripts/ci.sh browser
```

After the test report is written, `scripts/web-browser-capture.mjs` keeps main Running for at most
30–300 seconds (default 180). It atomically writes
`/workspace/weather-browser-capture/ready.json`, binding the trusted fetch-context detached checkout SHA (read from `.git/HEAD`, without a runtime Git dependency), Pod name, report
and synthetic screenshot SHA-256/byte counts. ROOT resolves and verifies the Workflow/Pod UIDs,
reads that exact manifest and copies every listed file using the existing operator identity while
main remains Running. Verify byte counts/hashes in retained custody, then atomically write
`/workspace/weather-browser-capture/captured.json` in the same exact Pod with:

```json
{"operation_id":"<same-stable-id>","source_revision":"<same-source-sha>","manifest_sha256":"<SHA-256 of exact ready.json bytes>"}
```

The capture helper checks the binding, writes its acknowledgement to the final bounded Workflow
report, and exits. Missing or mismatched acknowledgement fails qualification. The acknowledgement
records ROOT's custody claim; the retained independent file hashes are the custody proof. Collect
final report from the Workflow output parameter. No capture wait occurs when the optional operation
variable is absent. Do not use the hold in event/required CI, and do not recreate a timed-out operation.


The offline fresh-main integration receipt is
`evidence/web-offline-main-integration-20261024.json`. Its separate
`public-web-alignment-fcd8388-20261024.json` audit reads a detached immutable API source snapshot
without adding that unaccepted API stack to the web branch. It preserves the earlier failed native
Workflow/head as historical evidence; local source checks do not replace the eventual exact-head
required Fleet checks. Optional polling jitter is sampled once per request cycle, so one-second
source-age renders cannot continually reset the interval. Today retains zero jitter by default.


Strict-CSP qualification uses Zod's interpreted (`jitless`) path before schema construction. Its
normal caught eval-capability probe still emits a CSP violation in browsers, so fallback after the
probe is insufficient. The source regression blocks dynamic Function construction in a separate
Node process and verifies zero probes. The browser matrix checks the untouched hydrated app's CSP
before axe runs. Axe's own WebKit elements-from-point polyfill writes inline pointer-event styles;
that tooling noise is separated after the pre-scan assertion while all WCAG rules and non-style CSP
checks remain enabled. Production CSP is unchanged and allows neither inline scripts nor eval.

Rendition changes retain the current loaded playhead; pending seeks survive additional switches
while new metadata is loading. Initial viewport detection does not retain a stale zero snapshot
when the automatic role is unchanged. Framework errors use bounded renderer metrics; the default
React Router URL/stack logger is overridden so only the server's route-template/status/latency log
is emitted. The first real three-engine fixture run and its failed result remain retained for
comparison; a failed run is never treated as acceptance.

Playwright 1.64.1's WebKit 27.2 reports one false `style-src-attr` violation per native
`select` in its user-agent shadow tree (confirmed upstream:
https://github.com/microsoft/playwright/issues/43497 and WebKit 327212). Qualification
keeps the production CSP intact, requires no inline style attributes in the serialized SSR document, and compares
pre-axe violations to the exact native-select count only in that engine. A minimal empty/native
select control and a real forbidden-inline-style negative control run in every engine; the
negative control must add a violation. Other directives and all Chromium/Firefox violations
must be empty. A browser change that fixes the defect fails the control and requires removing
this narrow accounting. The retained failed browser03 run has 78 passes, 15 WebKit control
failures, and 21 checksummed screenshots; it is not acceptance.

History chart labels use two lines (date, then time and UTC offset) with a 150-pixel
minimum tick spacing and reserved axis height. This avoids overlapping full timestamps while
preserving the distinction between the two repeated 01:15 observations. The table retains exact
source timestamps. uPlot sizes its canvas using CSP-permitted JavaScript style properties;
qualification checks serialized HTML for inline style attributes, rather than forbidding those
legitimate computed dimensions.
