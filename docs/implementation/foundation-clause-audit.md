## Remaining evidence boundaries

Readiness distinguishes material architecture gaps from future implementation tests. A defined receipt/interface plus credible feasibility may be ready to implement while still unaccepted in production; a missing immutable-write mechanism, safe untrusted execution path or public-video transport is a planning gap. The closure index retains these distinctions. No initial-release requirement is waived by a fallback or a deferred issue.

The prior E01–E10 observations are dated evidence with explicit limits. Collector network isolation, writer fencing, role-specific denial, actual host NFS enforcement and complete independent recovery remain unproven. Existing issue prose and schemas do not establish a functioning security boundary. Public references and fleet standards guide design; they do not grant Weather credentials, capacity or shared-service mutation authority.
