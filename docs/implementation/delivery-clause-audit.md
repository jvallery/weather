## §16.2 — WX-02, WX-33, WX-34

- Use D01 supported fleet delivery with pinned dependencies/digests, dependency/license/SBOM/secret checks, retained artifacts, migrations, staged promotion/health and rollback. Application and FFmpeg builds run in admitted cluster builders into approved registry.

- Untrusted public/fork PR code runs only in admitted isolated synthetic execution without production secrets or reachability to cameras/DB/storage/inference/control plane; branch protection or an ordinary LAN runner does not prove isolation.
- Trusted integration/promotion has a separate narrowly scoped path. Never run fork checkout with privileged pull_request_target; verify denied network and identity authority rather than assuming labels confer isolation.
