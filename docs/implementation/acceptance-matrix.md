Each receipt records source revision, running digest, contract versions, admitted environment, observation time, exact inputs, expected/actual results, negative cases, private evidence reference and limitations. Attach evidence at the producer issues; WX-33 integrates it and WX-35 verifies the release. All qualifiers in a row must be covered before that row passes.

PA-05 runtime GPU qualification is conditional on enabling acceleration. The nine-device planning inventory and mandatory CPU fallback remain required even if acceleration stays disabled. Deferred WX-45/WX-46 do not gate initial release.

For planning closure, finish the ADRs and contracts, resolve material approach/admission questions, and assign actionable verification to every clause. For production closure, execute those tests and inspect actual behavior. These are distinct completion claims.
