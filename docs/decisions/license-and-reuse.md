# Project license and selective reuse

Accepted by Jason on 2026-10-23: **MIT with permissive reuse**. This resolves the owner choice reserved by Q15 and D01. [LICENSE](../../LICENSE) applies to Weather's original source and documentation; it does not relicense third-party material.

Use reviewed compatible permissive components selectively. Before importing code or assets, record the upstream repository, exact revision, imported paths, actual license file and relevant notices, modifications and transitive dependencies. Preserve required notices in distributions. A public repository or README badge does not establish permission to copy.

Copyleft code imports require separate review before copying; they are not authorized by this decision. Ideas may inform an independent implementation without copying source. Unlicensed or disputed projects remain references only. The accepted independent application direction remains unchanged.

FFmpeg build configuration, codecs, fonts, models and extension licenses remain separate dependency/distribution obligations. MIT for Weather does not establish that an arbitrary linked media build or bundled model is distributable under MIT. Keep an inventory of shipped components and their notices with release provenance.

No upstream application code was imported during this planning pass. The source-pinned research landscape identifies possible references, not a list of incorporated dependencies.
